TikTok Repost Cleaner

Scan your reposts by date and preview matches before optionally attempting to remove them.

Preview mode is the default.

Removal requires --apply and typing REMOVE. TikTok UI changes can cause skips. Always verify changes manually.

Quick start

Clone the project and install dependencies:

git clone https://github.com/zerryH/tiktok-repost-cleaner.git
cd tiktok-repost-cleaner
python -m pip install -r requirements.txt
python -m playwright install chromium

Preview dates (UTC inclusive)

python repost_agent.py --username YOUR_USERNAME --start 2024-07-20 --end 2024-08-15

Removal (optional)

python repost_agent.py --username YOUR_USERNAME --start 2024-07-20 --end 2024-08-15 --apply

Confirm in the terminal by typing REMOVE. Sign in manually in the opened browser. Your browser session stays on your device.

Limitations

  • GitHub Pages is only this guide; automation runs locally.
  • TikTok's repost tab and action menu selectors may change.
  • Posts may be missed; manually check all changes.
