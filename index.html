Everything in one tidy workflow

Useful tools for reviewing your repost history without handing over your account.

⌕

Repost preview

See video cards currently loaded in your Reposts tab before taking action.

◷

Keep recent posts

Set an inclusive From–To range for original video upload dates. This is not the date you reposted it; TikTok does not expose a reliable repost timestamp in this view.

⇩

Export links

Keep a local record of post links you reviewed. No server upload.

Ⅱ

Stay in control

Review the selected date range. The extension uses TikTok’s native repost control and skips uncertain states.

◉

Local by design

No TikTok password, cookies, or session tokens are collected by this project.

↻

Refresh anytime

Load more posts in TikTok and refresh the preview when you are ready.

The extension processes loaded reposts one at a time using TikTok's own repost control. It asks for confirmation, skips uncertain states and limits each batch to 100. Date filtering uses original video upload dates; repost timestamps are not exposed.

Up and running in a minute

Install the unpacked Chrome extension and use it on your own TikTok session.

01 / INSTALL

Download the extension

Download the ZIP and extract it. Open chrome://extensions and enable Developer mode.

02 / OPEN TIKTOK

Go to your Reposts

Sign in on TikTok.com normally and open your profile's Reposts tab. Scroll to load posts.

03 / REVIEW

Open the cleaner

Click the extension icon, open the panel, choose a From–To date range and review the matches. The extension opens each post and uses TikTok's own repost control.

What about iPhone?

This website is mobile-friendly, but a website cannot control the TikTok app or another Safari tab.

Safari on iPhone

You can read the guide and repository on iPhone. To automate actions inside iOS Safari, this project would need a separately packaged Safari Web Extension and iOS app. That is not included in this release.
