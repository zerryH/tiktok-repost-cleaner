TikTok Repost Cleaner

Preview the reposts currently loaded on your TikTok profile and open each post's own menu. You stay in control of every removal.

Important: no automatic bulk deletion.

The Chrome helper only finds visible video cards and opens their menu. You must choose TikTok's “Remove repost” action yourself and verify it. TikTok's page changes often, so detection may miss posts.

Chrome on Windows

  1. Download the project using the GitHub Code → Download ZIP option.
  2. Extract the ZIP.
  3. Open chrome://extensions and turn on Developer mode.
  4. Select “Load unpacked” and choose the chrome-extension folder.
  5. Open TikTok, sign in normally, visit your profile's Reposts tab, then click the extension.

Safari on iPhone

What works:

This page and the instructions work in iPhone Safari. However, iOS Safari does not let an ordinary website inspect or control the TikTok app or another browser tab. This Pages site cannot remove reposts on iPhone.

Direct Safari automation would require a separately packaged and installed iOS Safari Web Extension. This repository does not currently include that app.

Privacy

  • No TikTok password, cookies, or session tokens are requested.
  • The extension does not send your TikTok page data to a server.
  • It only runs on TikTok pages and uses the page already open in your browser.
  • Unofficial project; not affiliated with TikTok.
